# Rihaus Website (Next.js scaffold)

This repository contains a minimal Next.js scaffold for the Rihaus website, created as a starting point based on the reference site https://www.therihaus.com.

What's included
- Next.js app (pages-based)
- Basic styling and responsive layout

To run locally

1. Install dependencies

   npm install

2. Run the development server

   npm run dev

Notes
- The scaffold copies the structure and sections from the reference site. Replace placeholder text, images, and assets under /public as needed.
- I will now create a feature branch named `feature/rihaus-site` from this initial commit so we can continue work there.
